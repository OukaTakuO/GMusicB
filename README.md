# GMusicB

メモ帳で楽譜を書くだけで、MIDIファイルを作れるツールです。
プログラミングの知識もPythonのインストールも不要です(Windows用)。

作ったMIDIファイルは、DAWソフトに読み込んで、音色の調整やミックス、書き出しに使えます。

## ダウンロード

👉 **[最新版のダウンロードページ](https://github.com/ユーザー名/GMusicB/releases/latest)**

ページ下の **Assets** を開いて、**`GMusicB-v0.1.zip`** をダウンロードしてください。
(`Source code` と書かれたファイルは、開発者向けなので必要ありません。)

## はじめかた

1. ダウンロードしたzipを、デスクトップなど好きな場所に**展開**します。(zipの中から直接起動しないでください。)
2. `GMusicB.exe` をダブルクリックします。
3. 初めて起動したときに「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」** を押してください。
4. メニューで `1` を選び、曲の名前、テンポ、トラック名、楽器を答えると、楽譜ファイル(.txt)がメモ帳で開きます。
5. 音符を書いて、保存します。
6. GMusicBの画面に戻って `2` を選び、楽譜を選ぶと、`output` フォルダにMIDIファイル(.mid)ができます。

楽譜を直したら、同じ画面でもう一度 `2` を選ぶだけで、MIDIを作り直せます。終了は `q` です。
楽譜ファイル(.txt)を `GMusicB.exe` の上にドラッグ&ドロップしても、MIDIを作れます。
メニューの `3` を選ぶと、楽譜を保存するたびに自動でMIDIを作り直します。

`GMusicB.exe` と `_internal` フォルダは、必ず同じ場所に置いてください。

## 楽譜の書き方

```
tempo: 120

[track: Melody]
instrument: Flute
volume: 100
pan: 64

ド4 2                  # ドを2拍
[ド4 ミ4 ソ4] 2         # 和音を2拍
休 2                   # 2拍休み
C#4 1 80               # 英語表記もOK。末尾の数字はベロシティ(省略すると100)
ド4 1 | レ4 1 | ミ4 2   # 「|」は小節の区切り(見やすさ用で、音には影響しません)
@16 ソ4 2              # 16拍目から鳴らす
```

- `#` から行末まではコメントです。
- 音は、前の音の直後に自動で並びます。途中に行を足したり消したりしても、後ろの音は自動でずれます。
- 音名は `ド レ ミ ファ ソ ラ シ` と `C D E F G A B` のどちらでも書けます。`C#4` や `Eb4` のようなシャープ、フラットにも対応しています。
- 数字や記号は、全角で入力しても大丈夫です。
- 1つの楽譜に、`[track: 名前]` を複数書くと、複数のパートを作れます。

### 使える楽器

初めから使えるのは `Grand Piano` / `Oboe` / `Clarinet` / `Flute` です。

**楽器は増やせます。** `GMusicB.exe` と同じ場所にある `instruments.txt` をメモ帳で開いて、
`楽器名 = 番号` の形で書き足してください(番号はGM(General MIDI)の音色番号で、0〜127です)。
先頭に `#` が付いたよく使う楽器の候補が並んでいるので、`#` を外すだけでも使えます。
保存すれば、GMusicBを開き直さなくても、次の操作から反映されます。

`volume` と `pan` は0〜127で指定します。`pan` は64が中央です。

間違いがあると、「Melodyトラック 12行目: 音名が不正です」のように、場所を教えてくれます。

## 更新するとき

新しい版が出たら、新しいフォルダを**別の場所に**展開して、
自分の `songs` フォルダと `instruments.txt` を、新しいフォルダにコピーしてください。
古いフォルダに上書きすると、古いファイルが混ざって動かなくなることがあります。

## 今できないこと

- ドラムの音色には対応していません。
- Expression、Sustain、Modulation、テンポの途中変更には対応していません。
- Windows以外では動きません。

## 不具合・要望
